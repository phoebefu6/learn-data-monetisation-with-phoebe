# Learn Data Monetisation with Phoebe

Selling data outside the firm, in ten 45-minute sessions on two tracks.

- **Leader (b1-b4, no code):** three roads to data revenue, is it ours to sell, products, prices
  and partners, and the board call.
- **Analyst (a1-a6, hands-on in the browser):** three prices for one dataset, the sellable share,
  package and cost to serve, pricing a data product, partner deal maths, and the data product P&L
  desk.

Every widget runs one engine in the browser (`assets/dm-live.js`): three value lenses, a consent
funnel with a cell-size threshold over 1,152 cells, a cost curve, a price search over 110
prospects, three seeded deal routes and a five-year P&L desk with 5,000 seeded draws. An
independent Python build (`materials/dm_reference.py`) prints the same numbers. The running case,
Keelson Mutual's repair cost index, is constructed. Sources: MIT CISR's data monetisation research,
Doug Laney's Infonomics talks, the GDPR, Singapore's PDPA and PDPC guidance, the EU Data Act, IAS
38, Jian Pei's survey on data pricing, and company filings for reported deals.

Static site: open `index.html`, or serve the folder with `python3 -m http.server`.
